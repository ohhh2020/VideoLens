# VideoLens 现场演示脚本

## 1. 演示目标

用 3–5 分钟展示“输入视频链接 → 自动生成视频总结”的完整流程，突出实际应用价值。

## 2. 演示前准备

1. 安装依赖：`pip install -r requirements.txt`。
2. 安装并配置 FFmpeg。
3. 配置 `.env` 中的 API Key 和模型名。
4. 准备一个 3–8 分钟的可下载短视频。
5. 提前运行一次，确认目标站点可访问。
6. 准备一个本地 MP4 作为网络异常时的备份。

## 3. 演示流程

### 第 1 步：说明痛点

“大家看长视频时，通常需要先看很久才知道内容是否值得看。这个系统只需要粘贴一个链接，就能自动生成文字总结、时间线和关键画面。”

### 第 2 步：输入链接

在 Web 页面输入视频链接，点击“开始分析”。

### 第 3 步：展示处理过程

依次说明：

- 视频下载完成；
- 音频转写完成；
- 关键帧抽取完成；
- 画面理解完成；
- 总结生成完成。

### 第 4 步：展示结果

- 一句话总结：快速了解视频主题；
- 核心要点：视频讲了什么；
- 时间线：按时间定位重点内容；
- 关键词和标签：内容画像；
- 关键帧画廊：视频画面速览；
- 转写文本：完整文字稿。

### 第 5 步：说明应用价值

“这个系统可以用于网课学习、会议纪要、内容运营和知识管理。相比人工看视频，它可以大幅降低信息获取时间。”

## 4. 可能的提问与回答

**Q：为什么不直接训练视频大模型？**

A：训练多模态大模型需要大量 GPU 和训练数据。本项目采用“本地转写 + 关键帧采样 + 云端 VLM”的工程化路线，在有限资源下实现完整的视频理解能力，这也是调研论文中“高效 token 压缩”思想的应用。

**Q：如何保证关键帧有代表性？**

A：系统结合均匀采样和场景变化检测。场景变化大的地方会补充关键帧，避免只取到重复画面；同时限制最大帧数，控制调用成本。

**Q：没有 API Key 能运行吗？**

A：可以。语音转写完全本地运行，总结模块有规则回退，仍能输出文字稿、关键词和时间线；配置 API 后总结质量更高。

**Q：支持哪些视频平台？**

A：底层使用 `yt-dlp`，支持 Bilibili、YouTube 等大量平台，也支持 MP4 直链和本地文件。

## 5. 演示注意事项

- 不要现场临时换视频，提前固定演示素材。
- 视频不宜过长，避免等待时间影响演示节奏。
- 如 API 调用不稳定，提前准备规则回退演示路径。
- 展示输出目录中的 `result.json` 和 `summary.md`，证明结果可导出。
