# 云端模型接入

视觉理解与画面文字识别使用云端视觉模型；概览、结论、章节、问答与偏好归纳使用云端文本模型。项目不部署本地视觉生成或文本总结模型。

## 在设置中接入

首次启动后打开“设置”，分别填写“大模型（云端）”与“视觉理解（云端）”：

| 字段 | 填写方式 |
| --- | --- |
| `base_url` | 服务商提供的 OpenAI 兼容接口地址，通常以 `/v1` 结尾，不是管理页面或单个 `/chat/completions` 路径 |
| 模型名 | 服务确实支持且账号有权限调用的模型标识 |
| API Key | 服务商提供的完整密钥 |

地址与模型名默认留空。灰色 `qwen3.5-flash` 只是占位示例，不自动保存或发送；输入真实模型名后提示隐藏。两个通道可使用相同服务，也可分别接入。

文本通道须支持聊天补全与流式回答，视觉通道须支持图像输入。短视频段输入是服务商扩展，并非所有兼容服务都支持；不支持时可设 `vl.video_mode: frames`。

保存后通过“菜单 → 重启”加载云端配置。CPU/GPU 和报告显示的切换无需重启，云端地址、模型名或密钥变更仍需重启。

## 密钥显隐与保存

已保存密钥默认显示固定八个圆点 `●●●●●●●●`，不泄露首尾或长度。点击“显示”才读取完整值，“隐藏”收起；离开设置或保存后恢复隐藏。两项独立控制。

新输入的密钥会替换原值，未修改则保留。勾选清除且未输入新值时才清除。只查看密钥或保存其他设置不会覆盖原密钥。

## 初次启动和配置文件

云端未配置时仍可进入设置和浏览已有数据，分析与问答会明确要求先完成配置，不生成替代内容。三个本地模型仍须在启动时真实加载成功。

网页设置保存在源码外 `VideoLens-runtime/config/user_settings.json`，不要提交 Git。`configs/cloud-settings.example.json` 仅提供空值结构示例。`OPENAI_API_KEY` 和 `ZH_YING_VL_API_KEY` 可作为指定的密钥环境变量，重启后须确保新进程继承这些变量。

“配置已加载”不代表网络调用成功。错误的密钥、地址、模型权限和限流会在真实请求时报错；认证失败停止无意义重试，不切换本地生成模型。完成一次视频总结与问答可验证实际连接。
