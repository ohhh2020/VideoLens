# 知影使用手册

本机已经完成环境、权重和运行时配置，直接运行根目录的“一键启动.cmd”即可。新电脑从下文安装步骤开始。当前本机文本生成使用已验证的 llama.cpp CUDA，向量检索使用 CPU；没有配置云端视觉时，会明确提示画面描述/OCR 降级。

本手册按第一次使用的顺序介绍。命令示例中的 `VIDEO_ID`、`TASK_ID`、`SESSION_ID` 是占位符，需要替换为程序实际返回的 ID；它们用于区分不同视频、任务和对话。

## 1. 安装与目录

首先安装 Miniconda，然后在项目根目录双击 `一键配置环境.cmd`。脚本会查找 `conda`，读取环境列表并复用 `VideoLens`，不会把项目包安装进 `base`。不存在时创建 Python 3.13 环境，依赖兼容性失败时采用已约定的 Python 3.12 方案。已有环境修改前先导出清单到 `data/environment-backups/`。

首次完整配置包含基础依赖、ASR/向量依赖、FFmpeg、四类模型和 llama.cpp CPU 运行时。下载以固定版本为依据，文件校验通过后才记入清单；最后下载短人声样本并逐项执行真实 CPU 转写、文本向量、图文向量和本地生成检查。模型文件较大，网络断开后重新运行相同脚本，已完成文件会复用。脚本没有成功结束时，不能仅根据目录出现判断安装完成。

需要更细地控制时，使用 PowerShell 7：

```powershell
# 只安装依赖，模型与本地运行时稍后分别安装。
pwsh -File scripts/setup.ps1 -SkipModels -SkipRuntime

# 仅安装界面、API 与离线单元测试依赖。
pwsh -File scripts/setup.ps1 -Minimal

# 已知需要 Python 3.12 的机器可明确指定。
pwsh -File scripts/setup.ps1 -PythonVersion 3.12

# 只检查已有环境，不安装、不下载、不启动模型。
pwsh -File scripts/setup.ps1 -CheckOnly
```

`-SkipVerification` 可跳过真实模型检查，但脚本只会报告“部分配置完成”，不会宣称完整模型已经就绪。`-Minimal`、`-SkipModels` 或 `-SkipRuntime` 同样表示部分配置；最终验收应重新运行完整配置，或手动执行真实模型验证脚本并保留报告。

Windows 自带 PowerShell 5.1 对无 BOM 的 UTF-8 脚本容易使用错误编码。三个中文 `.cmd` 入口显式以 UTF-8 读取 PowerShell 文件，不需要修改文件编码。没有 PowerShell 7 时，优先双击入口；高级参数可按 `.cmd` 的 `Get-Content -Encoding UTF8` 方式调用。

默认数据在项目下的 `data/`、`models/`、`runtime/`。如需换到大容量磁盘，先停止服务，在 `config.local.json` 中设置对应路径。相对路径以配置文件所在目录为基准；绝对路径按原路径使用。迁移已有数据时，需要连同数据库、媒体目录、模型清单和实际模型文件一起迁移，并修正清单中记录的绝对路径；新手推荐首次下载前选好目录。

## 2. 启动、登录与退出

双击 `一键启动.cmd`。脚本先做基础导入与 FFmpeg 实际生成检查，再尝试启动已配置的本地模型，最后启动网页和 API。浏览器地址为 `http://127.0.0.1:8000/app`。

首次运行自动生成访问令牌，保存在 `data/.access-token`。用户名为 `videolens`，密码就是该文件全部内容。若设置了 `VIDEOLENS_API_TOKEN` 环境变量，则使用环境变量中的值。API 客户端也使用同一访问令牌。

网页关闭不代表后端已退出。请回到启动窗口按 `Ctrl+C`，等待退出。启动脚本只停止当前启动者创建且进程身份仍匹配的 llama 服务；不会按名称批量结束 Python 或其他程序。

没有部署本地生成模型时，启动窗口会提示降级并继续启动网页。此时仍可导入带字幕视频、抽帧、查看证据和基础摘录。需要真实语音转写与向量检索时，应完成对应模型下载。

## 3. 导入与分析

### 本地视频

在“导入”标签拖入 MP4、MKV、AVI 或 MOV，必要时同时上传 SRT、VTT 或 ASS 字幕。默认支持最多 2 小时、4,000,000,000 字节。系统会复制一份受管理视频用于处理和播放；不会修改原文件。

字幕优先于语音识别，适合已有课程字幕的场景。无可用字幕时，从视频提取 16kHz 单声道音频并使用 faster-whisper。没有音轨的视频仍可以抽取关键帧；没有云端视觉模型时，系统会报告视觉描述不可用。

### 视频链接

输入完整 HTTP/HTTPS URL。yt-dlp 能否解析取决于网站当前支持和访问条件；付费、登录、区域受限或已下架内容可能无法下载。失败会显示原因，不能把“提交成功”当成“下载成功”。默认视频下载开启，可在高级设置关闭。

### 开始分析

点击“上传并分析”或“获取链接并分析”，导入成功后自动创建分析任务。已经在视频库中的视频可以选择后点击“重新分析当前视频”。后台返回任务 ID，页面可查看获取、解析、转录、切片、关键帧、视觉、索引、报告等阶段的进展。默认重型分析并发为 1，避免同时加载多个大模型耗尽显存。

默认切片目标 20 秒、范围 10—30 秒，每片最多 3 帧；可以在设置页修改。静态或重复画面可能去重后少于设定帧数，属于正常行为。低分辨率源视频保持原始分辨率；不会把插值放大当成原生 720p。

## 4. 任务暂停、恢复和取消

- **暂停：**发出请求后在安全检查点停止，当前不可分割操作可能需要先结束，因此不是点击后立刻冻结。
- **恢复：**复用已经完成且配置兼容的检查点，从剩余阶段继续。
- **取消：**结束当前任务，并尝试中断由本项目启动的外部处理进程或模型请求；取消状态不会在重启后自动继续。
- **意外关闭：**重启时重新处理未完成的运行/排队任务；用户主动暂停和取消的任务维持该状态。

“部分成功”表示有可用产物且某些阶段降级，例如视觉接口未配置。必须阅读降级原因；“失败”表示关键流程无法继续，例如视频不可解码。

## 5. 查看报告与核对证据

报告包含摘要、章节时间线、关键词、标签、切片转录与关键帧。引用显示证据 ID 和时间。点击时间或选中切片可定位到视频对应位置。时间格式为 `HH:MM:SS.mmm`，内部使用整数毫秒，避免小数秒累积误差。

模型结论需要引用本次检索提供的证据；后端会拒绝不存在的 ID 和不一致摘录，失败时进行有限修正。引用检查证明“引用存在且原文匹配”，不自动证明模型对证据的解释正确。重要内容应点击证据返回视频核对。

当云端与本地文本模型均不可用，界面显示“基础摘录”等降级标识；此时内容是证据整理，不能当成完整的生成式总结。

## 6. 搜索与连续提问

在报告页输入问题可进行文字检索，或上传图片寻找相似关键帧。正常流程融合文本向量、图文向量和关键词三路候选；向量不可用时保留关键词结果。

创建会话后连续提问，历史只属于当前视频与当前会话。切换视频后应创建或选择对应会话，避免误把其他视频内容当成当前证据。信息不足时允许回答“证据不足”，不要将这种提示视为程序错误。

流式回答中间输出是生成过程，最终内容以完成事件和最终引用校验结果为准。网络中断或服务报错时，不能把尚未完成的片段当成成功的完整答案。

## 7. 配置云端和本地模型

### 云端文本与视觉

在设置页分别选择文本或视觉供应商，填写接口地址、模型名称、凭据引用名称和 API Key。接口需兼容 OpenAI Chat Completions；视觉模型还需支持 `image_url` 图片输入。保存后执行连接测试，再开启云端分析。

云端会接收到转录片段、检索证据、问题，以及视觉任务的关键帧；不会直接上传整段原视频。关闭 `cloud_enabled` 后不调用云端分析。模型下载与视频下载分别由独立开关控制；“不调用云端模型”不等于禁止下载公开模型。

API Key 只写入 Windows 凭据管理器。设置接口只返回凭据引用，不读回密钥；配置导出和 Git 不包含密钥。无法使用凭据管理器时，可在后端进程启动前设置 `VIDEOLENS_KEY_<凭据引用大写并替换特殊字符为下划线>`。

### 本地 llama.cpp

默认使用 `Qwen3-4B-Q4_K_M.gguf` 与 CPU 运行时。可以单独执行：

```powershell
conda run --no-capture-output -n VideoLens python -m videolens.bootstrap models --names local
conda run --no-capture-output -n VideoLens python -m videolens.bootstrap runtime
conda run --no-capture-output -n VideoLens python -m videolens.bootstrap start-local
conda run --no-capture-output -n VideoLens python -m videolens.bootstrap stop-local
```

GPU 运行时可通过 `runtime --variant cuda` 安装，但安装成功不表示当前显卡和驱动已兼容。确认真实推理通过后再调整 `llama_gpu_layers`；CPU 默认值为 0。显存不足时先减少 GPU 层数和上下文长度，不要同时启动多个重型分析任务。

自定义下载地址或已经下载的 ZIP 必须提供哈希：

```powershell
conda run --no-capture-output -n VideoLens python -m videolens.bootstrap runtime --archive "D:\下载\llama.zip" --sha256 "替换为64位SHA256"
```

## 8. 导出、清理和备份

报告页支持 Markdown 与 JSON 导出。Markdown 适合直接阅读，JSON 保留结构化字段和证据，适合二次开发。输出使用 UTF-8，中文与毫秒时间不会丢失。

受管理媒体副本默认保留 7 天，失败任务临时文件保留 24 小时；结果和索引默认长期保留。执行清理后媒体可能不能播放，但已保存的转录、证据和帧仍可阅读。需要重新播放时应重新提供原视频。按视频删除会删除该视频的业务数据与受管产物，原始文件不参与自动清理。

备份前先正常停止服务，将 `data/`、`config.local.json` 一并复制到备份目录。模型可按清单重新下载，下载不方便时也可备份 `models/` 与 `runtime/`。Windows 凭据管理器中的 API Key 不在这些目录中，迁移到另一台电脑时需要重新配置。

## 9. CLI 常用命令

除部署模型与启动服务外，业务 CLI 命令需要后端已运行。

```powershell
conda run --no-capture-output -n VideoLens python -m videolens --help
conda run --no-capture-output -n VideoLens python -m videolens doctor
conda run --no-capture-output -n VideoLens python -m videolens videos
conda run --no-capture-output -n VideoLens python -m videolens tasks TASK_ID --action pause
conda run --no-capture-output -n VideoLens python -m videolens tasks TASK_ID --action resume --follow
conda run --no-capture-output -n VideoLens python -m videolens ask VIDEO_ID "继续解释上一条结论" --session SESSION_ID --stream
conda run --no-capture-output -n VideoLens python -m videolens search VIDEO_ID --image "D:\图片\板书.png"
conda run --no-capture-output -n VideoLens python -m videolens reindex VIDEO_ID
conda run --no-capture-output -n VideoLens python -m videolens cleanup
```

## 10. 本地生成的 CPU / GPU 选择

本机 RTX 5060 已完成 CUDA 真实生成验收，当前 `config.local.json` 指向 `runtime/llama-cuda/llama-server.exe`，`llama_gpu_layers=99` 表示尽量把模型层放到显卡。BGE/SigLIP 的 PyTorch CPU 构建与 llama.cpp 的 CUDA 是两套运行时，因此“本地回答用显卡、向量检索用 CPU”是正常配置。

完整配置脚本默认安装 CPU 基线。需要切换 GPU 时先停止知影，再执行：

```powershell
# 安装固定版本 CUDA 运行时，不会安装或替换显卡驱动。
conda run --no-capture-output -n VideoLens python -m videolens.bootstrap runtime --variant cuda
```

随后在 `config.local.json` 将 `llama_gpu_layers` 设置为 `99`，重新双击启动；也可以在网页“完整配置”中修改，保存后按提示重启。本地模型的路径、上下文和 GPU 层数均需重启模型服务后生效。独立验证命令为 `python scripts/verify_llama_cuda.py`，只在自己的验收目录和 8082 端口运行，不修改主配置。

如果显存不足、驱动不兼容或同时运行大型游戏，停止知影后执行以下命令恢复已验证 CPU 路径，再启动：

```powershell
conda run --no-capture-output -n VideoLens python -m videolens.bootstrap runtime --variant cpu
```

配置工具会同时把 GPU 层数恢复为 `0`。它保留已下载模型和另一套运行时，不需要重新下载 GGUF。
