# 知影 VideoLens 使用教程

更新日期：2026-10-15。本文对应精简网页版本；旧版计划中的登录、多标签工作区、字幕上传框已取消。

## 1. 第一次打开

1. 将项目放在固定位置，例如 `D:\Project\VideoLens`。路径中可以有中文或空格。
2. 初次安装双击根目录的 **一键配置环境.cmd**。脚本会下载并校验 Miniconda，放到 `runtime/miniconda3`，建立 `envs/VideoLens` 环境，再安装 Python 依赖、FFmpeg 和模型。不会安装到系统 Python 或 base。
3. 本机完成配置后，日常直接双击 **一键启动.cmd**。不要每次使用都重新配置环境。
4. 等待启动检查完成，打开 `http://127.0.0.1:8000/app`。**无需用户名或密码。**启动窗口要保持运行。
5. 首次建议分析一个 30 秒到 2 分钟的清晰短视频，确认输入、报告、问答都正常后，再处理长视频。

一键启动优先使用系统已有 Edge/Chrome 的独立资料目录 `cache/browser`，下载目录默认是 `data/exports`。如果手动在自己的浏览器打开，请将该浏览器的下载目录设到项目内，否则浏览器可能把报告副本写到系统“下载”目录。VideoLens 无法控制操作系统的事件日志、浏览器自身更新或显卡驱动的系统数据。

## 2. 页面只有三部分

| 区域 | 你需要操作的内容 |
|---|---|
| 设置（默认折叠） | 刷新视频库；云端模型；本地 llama.cpp 模型下载、导入、启停、删除；系统提示词 |
| 输入 | 当前视频、本地视频、视频 URL、分析按钮、问答提示词、发送问题 |
| 输出 | 自动更新的分析进度、`.md` 报告下载链接、直接显示的问答回答 |

高级任务控制、检索、清理和 JSON 导出仍由 CLI/API 提供，不再占用日常网页。

## 3. 分析本地视频

1. 把 MP4、MKV、AVI 或 MOV 拖到“本地视频”，或点击控件选择文件。
2. 将“视频 URL”留空。
3. 点击“分析视频”。当前视频会自动切换到此次导入的视频。
4. 输出区会显示排队、分析阶段及百分比。首次加载向量模型比较慢，终端中可查看日志。
5. 完成后点击“下载分析报告（.md）”。报告为 UTF-8 Markdown，可使用记事本、VS Code、Obsidian 等打开。证据 ID、时间戳及降级说明保留在报告内。

网页没有单独的字幕上传项。内嵌字幕可自动识别；没有可用字幕时使用本地语音转写。浏览器只上传你选的视频，无法自动读取它旁边的同名 SRT；如需利用本机同名字幕，可使用 CLI 本地路径导入。没有音轨且没有云端视觉时，系统会明确说明可用证据不足。

已有视频重新分析：先清空本地文件和 URL，从视频库选择视频，再点“分析视频”。相同内容和兼容配置可能复用已完成任务。更改系统提示词后重新分析才会生成新版报告。

## 4. 分析在线视频

1. 清空本地视频控件。
2. 在“视频 URL”填入可公开访问的视频页面链接。
3. 点击“分析视频”，等待下载和分析。平台的字幕若能获取会优先使用。

支持范围取决于 yt-dlp、网站策略与网络。需要登录、验证码、付费权限或区域限制的视频不保证能直接下载；可以先通过合法方式保存为本地视频再导入。默认限制为 2 小时、4GB。

## 5. 持续问答

1. 从“视频库 / 当前视频”选择一个已分析的视频。
2. 在“问答提示词”输入问题，例如：
   - “按时间顺序列出视频的三个核心观点，并引用证据。”
   - “视频中提到的操作步骤是什么？请面向初学者解释。”
   - “刚才第二个步骤有哪些注意事项？”
3. 点击“发送问题”，输出区直接显示回答。可以继续发送下一问，同一视频的当前页面会话会保留上下文。
4. 切换视频或重新分析时会开启新的页面会话，避免引用另一个视频。刷新页面也会重新开始页面会话；之前的会话记录仍保存在 SQLite，CLI/API 可查询。

生成过程中是草稿，最终回答经过引用校验。若连接断开，页面会标记“回答未完成”；若模型不能提供可靠结论，会显示原文摘录或证据不足，不能把它当作模型正常生成。

## 6. 推荐的模型组合

以下是根据官方文档和本机条件给出的选择建议，不表示已用你的账号完成云端实测。模型是否可调用、地域、额度和价格，以平台控制台为准；不建议初次就选最昂贵的最大模型。

| 需求 | 建议 | 说明 |
|---|---|---|
| 中文视频入门 | 百炼 `qwen-plus` 做总结问答，`qwen3-vl-plus` 做视觉 | 文本与视觉分开配置，便于控制成本；模型 ID 需确认所在业务空间开放 |
| 单个云端模型兼顾图文 | OpenAI `gpt-6-luna` | 官方文档列出文本/图像输入和 Chat Completions；本项目对它使用非推理模式，适合先验证流程 |
| DeepSeek 替代方案 | `deepseek-flash` | 当前官方页面列出图像能力；不要照搬旧教程中的 `deepseek-chat`。`deepseek-v4-pro` 当前页面未列出视觉支持，不应填到视觉用途 |
| 本机 RTX 5060 8GB | `Qwen3-4B-Q4_K_M.gguf` | 已有本机真实推理基线。建议上下文 8192、GPU 层数 99；内存不足时先降为 4096 或 CPU（层数 0） |

参考：[百炼 Chat API](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions/)、[百炼视觉接口](https://help.aliyun.com/zh/model-studio/qwen-vl-compatible-with-openai)、[OpenAI GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna)、[DeepSeek 模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)、[Qwen3-4B GGUF](https://huggingface.co/Qwen/Qwen3-4B-GGUF)。

4 位量化模型只压缩了权重，运行时还需要上下文缓存和工作空间；“模型文件 2.33GiB”不等于“只占 2.33GiB 显存”。本地 Qwen 是文本模型，不会自动看懂关键帧；画面描述和 OCR 仍需启用云端视觉服务。

## 7. 云端配置教程：阿里云百炼

### 获取 API Key 和模型 ID

1. 进入 [百炼控制台](https://bailian.console.aliyun.com/)，登录自己的账号，开通模型服务并检查计费/额度。
2. 选择需要的地域和业务空间。打开 API Key 管理，创建密钥；如果使用子业务空间，确认该空间已获得目标模型的调用权限。
3. 复制新生成的 API Key。在目标模型的调用示例中确认模型 ID 和 OpenAI 兼容 Base URL。
4. 北京地域的新地址是 `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`，要把 `{WorkspaceId}` 替换为真实业务空间 ID。官方仍说明旧地址 `https://dashscope.aliyuncs.com/compatible-mode/v1` 可用。不要混用其他地域的密钥和地址。

详细入口以 [官方 API Key 教程](https://help.aliyun.com/zh/model-studio/get-api-key) 和 [接口地址说明](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions/) 为准。页面会随平台更新，关键是“同一地域、同一空间、正确模型权限”。

### 在知影填写文本模型

展开“设置 → 云端模型”，按下表填写：

| 字段 | 示例 |
|---|---|
| 用途 | 总结与问答 |
| 启用此用途的云端模型 | 勾选 |
| 允许云端分析（总开关） | 勾选 |
| 接口 Base URL | 控制台提供的 OpenAI 兼容地址，末尾为 `/compatible-mode/v1` |
| 模型 ID | `qwen-plus`，或控制台明确授权的文本模型 ID |
| API Key | 刚创建的密钥 |
| 上下文预算 | 先填 `8192` 或 `16384`，不要超过模型实际容量 |
| 请求超时 | 先填 `120` 秒 |

点击“保存云端设置”。API Key 输入框会清空，这是正常行为，密钥不会回读到页面；之后留空保存表示保留原密钥。点击“测试连接”。目前连接测试读取模型列表，证明地址和凭据能连通，**不等同于该模型完成了一次生成或视觉识别**。

### 再配置视觉模型

切换用途为“画面理解与 OCR”，启用该用途，使用同地域地址，模型填 `qwen3-vl-plus`。这个用途有独立密钥引用，因此初次也要粘贴一次 API Key，再保存。可以给文本和视觉使用同一个平台的同一把 Key，也可以分别使用两个平台。

最后导入一个含清晰文字和语音的短视频，检查报告是否仍提示“视觉不可用”，再问一个只能根据画面回答的问题。这个步骤才是在自己的账号上验证图文能力。

## 8. 云端配置教程：OpenAI / DeepSeek

**OpenAI：**进入 [OpenAI API 平台](https://platform.openai.com/)，在自己的项目中创建 API Key、确认 API 计费与模型权限。按照上节表格操作，Base URL 填 `https://api.openai.com/v1`，模型 ID 可选 `gpt-6-luna`；文本和视觉用途分别保存。API Key 获取与调用步骤见 [官方快速开始](https://developers.openai.com/api/docs/quickstart)。本项目使用 Chat Completions；对 GPT-5/6 官方接口自动适配输出预算参数，对 GPT-6 Luna 使用 `reasoning_effort=none`。[参数兼容说明](https://developers.openai.com/api/docs/guides/latest-model)

**DeepSeek：**在 [DeepSeek 开放平台](https://platform.deepseek.com/) 创建 API Key，检查余额与模型权限；Base URL 填 `https://api.deepseek.com`，模型 ID 填 `deepseek-flash`。地址不需要手动追加 `/chat/completions`，程序会自动追加。模型名称与视觉支持请再核对 [官方模型表](https://api-docs.deepseek.com/quick_start/pricing/)。

费用控制建议：先测一分钟视频；视觉描述按关键帧调用，长视频可能产生大量请求；在平台设置预算/额度提醒。关闭“允许云端分析（总开关）”并保存后，后续分析与问答不会向云端模型发送内容；此前已经发送的数据不可能由本地开关撤回。

## 9. 本地 llama.cpp：完全通过网页操作

### 使用已有默认模型

1. 展开“设置 → 本地模型 · llama.cpp”。
2. 选择模型，RTX 5060 可先设 GPU 层数 `99`、上下文 `8192`。
3. 点击“应用并启动所选模型”，等待显示健康检查通过。无需重启网页。
4. 回到输入区分析或问答。云端开启时文本模型优先云端，失败再尝试本地；要只用本地，关闭云端总开关。

### 下载模型

1. 展开“下载 / 导入模型”。默认已填入固定版本 Qwen3-4B 的 HTTPS 直链及 SHA-256。
2. 点击“下载模型”，在“模型运行与下载进度”查看字节进度。
3. 校验完成后模型会出现在下拉框，选择并启动。
4. 更换其他模型时，填写它的**单个 GGUF 文件直链**和发布者提供的 SHA-256。Hugging Face 文件详情页可查看 LFS 文件的 SHA-256。仓库首页、HTML 下载页或 ZIP 地址不能作为 GGUF 输入。

文件逐块写入 `.part`，只有完整性与 GGUF 头检查通过后才发布。文件校验通过不代表此 llama.cpp 版本支持该架构；以“应用并启动”的健康检查为准。不支持分卷 GGUF 或需要独立视觉投影器的本地视觉模型。下载失败会删除本次半成品，重新点击会重新下载；原固定模型部署工具有自己的缓存复用机制。

### 导入已有模型

将完整路径粘贴到“已有 GGUF 的本机完整路径”，例如 `D:\模型\Qwen3-4B-Q4_K_M.gguf`，点“导入模型副本”。为避免浏览器重复上传数 GB 文件，网页读取本机路径并流式复制到 `models/gguf`。原文件保留；相同 SHA-256 的模型不会在这个库里重复存储。

### 删除或切换

先停止当前模型，再选择要删除的项目内模型，勾选确认并点击“删除所选模型”。分析或问答进行中会阻止停止/删除；等待完成后重试。删除当前选中的模型会停用本地生成，需选择其他模型再启动。

旧版安装的默认模型属于 Hugging Face 共享快照，在网页标识为已有安装模型；网页不会直接删除共享缓存，以免损坏模型清单。通过本页导入或下载的独立副本可以删除。ASR、BGE-M3、SigLIP2 属于分析依赖，不在 GGUF 删除列表中。

### 安装 / 切换运行时

在“删除模型 / 部署运行时”中选 `cpu` 或 `cuda`，先停止模型，再点“下载并部署 llama.cpp”。下载完成后重新选择模型并启动。CUDA 运行时并不保证所有显卡都兼容；失败时换 CPU 运行时、GPU 层数设 `0`。

## 10. 系统提示词

“分析报告系统提示词”决定报告风格，例如：“面向零基础读者，先给概览，再列操作步骤，保留时间戳与证据引用。”

“问答系统提示词”决定回答规则，例如：“使用简体中文；先给直接答案，再解释依据；无法从视频判断时明确说明。”

点击保存后，新问答使用新提示词，旧报告不会自动重写。提示词不能补充视频中没有的事实，仍需保留证据约束。

## 11. 文件都放在哪里

| 项目内位置 | 用途 |
|---|---|
| `runtime/miniconda3/` | 本项目独立的 Miniconda 管理程序 |
| `envs/VideoLens/` | Python 和 Python 软件包，日常运行只使用此环境 |
| `cache/conda/pkgs/`、`cache/pip/` | Conda/pip 下载缓存 |
| `cache/tmp/`、`cache/gradio/` | 临时文件、上传缓存，Gradio 定期清理过期缓存 |
| `cache/huggingface/`、`cache/torch/`、`cache/cuda/` | 模型工具和计算缓存 |
| `cache/home/`、`cache/appdata/`、`cache/localappdata/` | 本进程中使用用户目录默认值的库的数据 |
| `cache/browser/`、`cache/browser-disk/` | 一键启动专用浏览器资料与缓存 |
| `models/` | 已校验模型快照与独立 GGUF 仓库 |
| `runtime/` | FFmpeg、llama.cpp、安装包与进程记录 |
| `data/` | 数据库、视频副本、帧、报告、会话及验证材料 |
| `data/secrets/` | Windows DPAPI 加密的 API Key 文件 |
| `data/exports/` | 点击下载时写出的报告原件；浏览器下载也默认落在这里 |
| `logs/videolens.log`、`logs/llama-server.log` | 应用与本地模型日志 |

以上目录均被 Git 忽略。不要在网页把模型/数据目录改到其他盘，也不要用 `pip install --user`。用户主动导入的原视频/原 GGUF 可以位于别处，程序只读取并在项目中保存副本；不会擅自移动个人源文件。Windows 的 DPAPI 主密钥由操作系统维护，不属于可迁入项目的软件数据，项目保存的是加密后的密文。

## 12. 日志和问题排查

日志示例：

```text
[2026-10-15 10:20:30][INFO][任务ID]: 执行阶段：frames，进度：45
[2026-10-15 10:20:31][INFO][llama.cpp]: 模型运行信息
```

时间是本机时间；INFO 表示进度，WARNING 表示降级/提醒，ERROR 表示失败。分析任务记录任务 ID，其他操作记录线程名；CLI 输出的 JSON、安装工具的进度条属于命令结果，不添加日志前缀以免破坏解析。

| 现象 | 处理 |
|---|---|
| 网页仍显示旧布局 | 关闭旧服务，重启一键启动，刷新页面；确认访问 8000 端口 |
| 401 / 密钥无效 | 用途选对后重新保存 Key，确认地域与业务空间匹配 |
| 404 / 模型不存在 | Base URL 不要多加 `/chat/completions`；核对模型 ID 与权限 |
| 429 | 检查额度或限流，减少调用，稍后重试 |
| 连接测试成功但生成失败 | 列表接口成功不代表生成成功；检查模型是否支持流式、图像及请求参数 |
| 本地模型启动失败 | 查 `logs/llama-server.log`；先用 CPU、较小上下文；检查 GGUF 架构和内存 |
| 操作提示任务忙 | 等待分析/问答结束再换模型或配置 |
| 报告为基础摘录 | 云端及本地生成均不可用或引用校验未通过；检查模型运行状态 |
| 换 Windows 用户后 Key 失效 | DPAPI 与用户绑定，重新填写密钥即可 |

## 13. 关闭、测试与命令行

回到启动终端按 `Ctrl+C`。脚本按进程身份清理本次启动的模型，网页启动的模型也随服务正常关闭而退出。Conda 若询问终止批处理，选择 `N` 让外层清理继续执行；不要靠强制关闭窗口实现日常退出。

双击“一键测试.cmd”运行自动化。开发命令请在项目根目录用明确的环境路径：

```powershell
# 不依赖外部同名 Conda 环境。
.\envs\VideoLens\python.exe -m videolens doctor
.\envs\VideoLens\python.exe -m videolens analyze "D:\视频\课程.mp4" --wait
.\envs\VideoLens\python.exe -m videolens ask VIDEO_ID "核心结论是什么？" --stream
.\envs\VideoLens\python.exe -m videolens export VIDEO_ID --format markdown --output "data\exports\笔记.md"
```

API/CLI 仍通过 `data/.access-token` 内部令牌访问后端。它不再是网页登录密码，无需人工输入到网页。完整开发信息见 [开发手册](开发手册.md) 与 [API 文档](API文档.md)。
