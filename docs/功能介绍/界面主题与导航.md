# 界面主题与导航

知影使用本地头像资源，显示于页面左上角、视频报告和普通/流式回答旁。头像保存在 `frontend/workbench/assets/zhiying-avatar.jpg`，不依赖外部图片服务，明暗主题共用同一张原图。

记忆库统一收纳在一个默认折叠的“记忆空间”中，不按类别拆分。展开后查看文字、多选或全选删除；新建与修改使用弹窗。开关与文件位置收纳在独立的设置折叠区。

## 外观与切换

工作台使用微软官方 **Fluent UI Web Components 3.1.3**，主导航、发送、附件与新对话按钮均为实际 Fluent 组件。组件脚本随源码本地提供，打开网页不需要访问 CDN，也不需要额外安装 Node.js。

右上角的主题选择与设置页的“界面主题”均提供：

| 模式 | 展示 |
| --- | --- |
| 浅色 | 柔白背景、浅灰层级、深色正文，玻璃表面带少量中性色 |
| 深色 | 深灰背景、稍亮面板、柔白正文，减少高饱和色与阴影 |
| 跟随系统 | 随操作系统的明暗设置自动切换 |

主题选择立即生效并保存到运行目录的 `config/user_settings.json`，配置项为 `ui.theme_mode`，取值 `system`、`light`、`dark`。无需重启服务。浏览器本地存储保留首屏主题以减少刷新闪烁；其他已打开标签页同步切换。

侧栏、输入区域与按钮使用半透明玻璃材质，文字导航使用克制的新拟物凹凸层次。强调色使用低饱和中性色，替换 Fluent 默认品牌蓝。Markdown、代码块、设置、记忆库和视频库随主题切换。浏览器不支持背景模糊时采用普通面板背景。

## 首页与历史

- 打开 `/ui` 显示空白视频工作台，历史抽屉默认隐藏，不自动打开旧会话，也不写入空会话。
- “新对话”仅清空当前视图和待发送附件，不创建数据库记录；已提交的后台任务继续执行。
- 选择或拖入视频只显示附件预览。首次发送含视频链接或附件的消息时才创建会话并开始处理。
- 首次只发送文字时，在页面提示提供视频，不创建空会话。
- 点击“历史对话”按需展开玻璃抽屉；点击“收起”、遮罩或按 Esc 关闭。在宽屏和窄屏下均保持该行为。
- 历史列表保留分页、重命名与删除。打开带 `conversation` 参数的明确会话链接会恢复该会话，但历史抽屉仍默认隐藏。

## 前端依赖维护

日常运行仍按现有 Conda 启动流程。只有修改 Fluent 组件入口并重新打包时才需要 Node.js 24 和 npm。在项目根目录的 Git Bash 中运行：

```bash
npm install --prefix ../VideoLens-runtime/cache/ui-build --no-save --package-lock=false @fluentui/web-components@3.1.3 @fluentui/tokens@1.0.0-alpha.24 @microsoft/fast-element@3.1.2 tslib@2.8.1 esbuild@0.25.12
node scripts/build_fluent_ui.mjs
```

依赖目录位于源码外的运行缓存中。入口为 `frontend/workbench/fluent-entry.js`，产物为 `frontend/vendor/fluent-ui.min.js`；构建脚本同步更新 `versions.json` 中的 SHA-256。打包使用的第三方许可证见[开源协议与第三方依赖](../开源协议与第三方依赖.md)。

前端交互回归需要源码外的 jsdom，运行 `tests/test_theme.js`、`tests/test_chat_stream.js` 和其余工作台测试。自动化覆盖系统主题、即时切换、保存顺序、空首页、纯文字引导、附件预览和首次发送去重；真实浏览器另检查 Fluent 组件、玻璃材质及窄屏布局。
