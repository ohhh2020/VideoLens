# 视频库与历史对话双向删除验收

日期：2026-11-01。

## 行为

- 删除视频库视频：清理对应视频及它的全部历史会话、消息、问答、报告、索引、切片、关键帧与受管缓存。
- 删除已绑定视频的历史会话：走同一清理流程，因此同视频的其他会话也会删除。确认框明确提示范围。
- 未绑定视频的草稿只删除自身和未被其他记录引用的附件。
- 任一关联会话正在分析/问答、视频有运行中的分析任务时拒绝删除。
- 其他视频/草稿仍在使用的上传文件保留；用户自行提供的外部原始文件不作为受管缓存删除。
- 运维日志、已结束任务的运维历史、模型权重及运行环境独立保留。
- 删除后同步刷新视频库与历史列表，清空受影响的播放器和会话，已打开的同源标签页同步处理。

## 旧页面兼容

旧网页的确认框曾声明删除会话会保留视频。带浏览器请求标识但未带新删除确认标记的旧页面请求会返回409并提示刷新，防止旧文案对应新删除行为。新资源已更换缓存版本。内部自动化调用继续走统一删除逻辑。
