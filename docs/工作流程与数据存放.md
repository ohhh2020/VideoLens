# 工作流程与数据存放

## 分析流程

浏览器上传本地视频或发送包含视频链接的文本 → 云端任务助手选择真实来源、提取随附问题 → 创建持久化会话操作 → 后端编排器按阶段执行 → 先保存分析报告，再自动回答随附问题。页面只通过会话 SSE 订阅进度与回答，刷新或离开页面不会重复提交后台操作。旧内部分析入口继续供已有工作流使用。

1. `backend/media/parser.py` 校验来源，生成视频 ID。
2. `backend/media/downloader.py` 下载网络视频；网页本地附件读取运行目录中已上传的文件，原内部路径入口仍可读取原路径。
3. `backend/media/ffmpeg_utils.py` 探测时长和音轨，抽取单声道 WAV。
4. `backend/models/asr.py` 优先解析可用字幕，否则使用必需的 Whisper small 生成带毫秒时间戳的转写。加载和推理错误直接使任务失败。
5. `backend/segmentation/scenes.py` 与转写并行检测镜头；切片形成后，再去重与抽取关键帧。
6. `backend/segmentation/chunker.py` 按标点、静音和时长合并转写，形成带重叠的时间切片。
7. `backend/models/vl.py` 把多帧图片或短视频段发给云端视觉模型，生成画面说明和画面文字。
8. `backend/models/embed.py` 用 BGE-M3 编码文本，用 SigLIP2 编码图片及图文查询。禁止哈希编码替代；异常结束任务。
9. `backend/pipeline/stages/indexing.py` 写入新一代向量，成功后切换活动代；失败保留上一代。
10. `backend/pipeline/stages/reports.py` 基于转写、切片及画面证据调用云端文本模型总结。

启动时 `backend/pipeline/factory.py` 负责装配和必需模型的真实预热，默认保留权重供后续请求使用。新版先完成画面与独立OCR取证，再把完整证据送入向量化，避免提前只编码语音；BGE 与 SigLIP 分别持锁。各阶段实现分别在 `backend/pipeline/stages/`，编排器负责流程和状态，网页路由不直接加载模型。并发参数及自动耗时汇总见 [模型并发与性能优化](模型并发与性能优化.md)。

## 问答流程

统一网页 `/ui` → 智能层判断当前视频问题 → 保留本轮原问题及约束，结合上一轮主题补全检索问题（可配置云端改写）→ BGE 文本、SigLIP 图文及 BM25 三通道检索 → RRF 合并 → 拼接证据 → 云端流式生成 → 校验引用 → 返回可跳转的视频时间范围。服务端问答历史按会话隔离；旧 `/chat` 地址重定向至主页面。

模型或网络异常会明确报告失败。证据校验发现缺少引用时仍会提示并补充出处；该提示与本地模型降级无关。

## 路径

以下路径都在 `VideoLens-runtime/` 下：

| 路径 | 内容 |
|---|---|
| `config/user_settings.json` | 云端密钥和网页偏好 |
| `models/bge-m3`、`models/faster-whisper-small`、`models/siglip2-base` | 必需模型权重 |
| `data/videos/<video_id>/source.mp4` | 网络下载的视频；本地输入可能仍在原路径 |
| `data/uploads/local-<附件ID>.<扩展名>` | 本地视频的文件软链接，指向原路径；不是完整视频副本 |
| `data/uploads/sha256-<内容指纹>.<扩展名>` | 旧上传链路保留的缓存副本；新网页本地入口不再写入 |
| `data/audio/<video_id>/audio.wav` | 抽取音频 |
| `data/frames/<video_id>/*.jpg` | 关键帧 |
| `data/analysis-runs/<run_id>/` | 新分析的隔离目录：`stage.sqlite3`、`evidence.sqlite3`、`source/`、`frames/`、`audio/`、`ocr/`；成功后才发布活动版本 |
| `data/uploads/up*.part` | 持久化续传中的文件，分块哈希与进度记录在主库 `upload_sessions`，24小时活动保留 |
| `data/zhiying.db` | 视频、切片、转写、帧关联、任务、报告、问答，以及会话、消息、操作状态与附件关联 |
| `data/memory/preferences.json` | 偏好文字、向量与历史归纳状态 |
| `data/chroma/` | 文本和图像检索向量 |
| `data/exports/` | 后端生成的报告或对话导出；浏览器下载还可能在浏览器下载目录 |
| `cache/temp/` | 临时视频段与下载中间文件 |
| `cache/huggingface/` | 模型下载缓存 |
| `cache/pycache/` | Python 字节码 |
| `logs/YYYY-MM-DD-CNT.log` | 每次启动独立的运行日志，同日序号从 1 递增 |
| `state/server.json` | 服务进程信息，正常退出后删除 |
| `tests/` | 自检生成的合成音视频和临时数据库 |

切片默认是数据库中的文字、时间范围和帧关联，不会为每个切片保存独立 MP4。云端视频段输入会短暂生成 MP4，调用结束后自动清理临时目录。

首次运行按[快速上手](快速上手.md)创建并激活 Conda 环境，安装依赖并准备模型，启动后在网页填写云端配置。日常重启会继续读取运行目录内已有的业务数据和设置。

FFmpeg 不在运行目录中部署，由用户手动加入系统 PATH。Python 3.13 环境由 Conda 管理，项目库通过已激活环境的 python -m pip install -r requirements.txt 安装；运行数据单独保存在 VideoLens-runtime。

## 完整性版本与追溯

`backend/analysis/` 集中实现版本隔离、证据、扫描取帧、独立OCR、云端调度、分层摘要、动态问答与资源检查。主库 schema 8 采用增量迁移；从旧库升级前创建 `<原库名>.before-v8.bak`。旧视频不因为本次算法或参数变化被清空。

新任务参数和提示词原文在接受时固定，不保存API Key。每条语音、画面、OCR证据都有稳定ID与真实时间来源；字级对齐转写按对应时间分配，无法精确对齐的原文保留原语音段范围。静帧引用不会被描述成连续观看。

`evidence.sqlite3` 中 `evidence` 保存原文，`results` 保存原始转写与字级时间、采样点、OCR原始结果、阶段、摘要树及覆盖清单，`requests` 是成功请求缓存，`calls` 是实际调用与失败记录。两者不能相加当作调用量。

显式强制重跑在新运行目录构建，成功后通过事务切换主库与活动向量代；失败时旧报告仍可读取。旧版本产物不会被自动删除。重启只标记中断，用户点击重试后使用同一任务快照并补齐未完成阶段。缓存和磁盘不足时停止写入，不自动删业务数据。

## fast-v3 性能回退

新任务固定时间抽帧，整帧批量概述与OCR，不再进行像素变化扫描/局部加密、原像素裁图或分层章节摘要。报告采用一次生成、最多32片全片均匀取样。未选入报告上下文的原始证据仍可检索，不标为全片事实已全部总结。

数据目录边界不变。fast-v3通常不产生 `ocr/` 原像素裁图，`summary_tree` 为空；`coverage.representative=true` 表示报告的代表性取样范围。旧版的摘要树和裁图保留，不自动删除或重算。

## 视频与会话的双向删除

视频库和历史会话共享联动清理流程。删除视频清理全部绑定会话；删除已绑定视频的会话同样清理对应视频、该视频的其他会话、问答、报告、切片、帧、向量、所有分析版本与受管下载/上传副本。没有视频的草稿仅清理自身及未被其他记录引用的上传附件。

数据库里的视频、会话和问答记录在同一事务删除，未关联外键的旧问答表也显式清理。删除与新追问提交互斥，任一关联会话仍在处理或视频正在分析时拒绝删除；索引删除失败时保留数据库记录并返回错误。其他视频或草稿仍引用的上传文件继续保留，用户源码目录之外自行选择的原始素材不由缓存清理流程删除。运行日志、任务运维历史与模型环境独立管理。

网页在删除前明确提示影响范围；删除后同步刷新视频库、历史栏，清空被删视频的播放器与当前会话，其他已打开的同源标签页通过删除事件同步。未对当前已有视频和历史做批量清理。

## 本地原文件与视频库展示

本地选择由 `backend/media/local_video.py` 调用系统文件选择器，网页不靠文件名扫描磁盘猜测路径。选择阶段不创建会话；发送后通过FFprobe校验，再创建受管软链接附件。流水线保留链接作为访问路径，以真实目标路径生成视频身份，重复选择同一文件可复用已有结果。缓存容量统计使用链接本身大小，清理操作先判断链接位置，只unlink链接，不resolve后删除目标。

视频库通过批量查询取得最近活动的已命名会话标题；没有已命名会话时显示原视频标题。云端展示原URL与文件缓存入口；本地展示真实目标地址。原始视频元数据标题仍保留，列表展示不改写旧报告。
