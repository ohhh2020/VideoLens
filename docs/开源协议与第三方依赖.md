## 外部模型与依赖

模型来自 [BAAI/bge-m3](https://huggingface.co/BAAI/bge-m3)、[guillaumekln/faster-whisper-small](https://huggingface.co/guillaumekln/faster-whisper-small)、[google/siglip2-base-patch16-224](https://huggingface.co/google/siglip2-base-patch16-224)，使用时遵循相应模型卡和许可。本项目的许可不覆盖第三方权重。

Python 依赖分别适用自身许可证；FFmpeg 的许可取决于用户选择的构建。云端服务适用服务商的调用、费用与数据处理条件。
