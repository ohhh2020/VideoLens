# 快速上手：FFmpeg、Conda 与启动

适用 Windows + Git Bash，假设 Conda 已安装且能在 Git Bash 中使用。项目路径仅为示例，请替换为实际路径。

## 1. 安装 FFmpeg 并加入系统 PATH

从 [FFmpeg 下载页](https://ffmpeg.org/download.html#build-windows)选择 Windows 构建，解压到例如 `D:/Tools/ffmpeg`。确认同一个 `bin` 目录中有 `ffmpeg.exe` 和 `ffprobe.exe`。

在 Windows“系统属性 → 高级 → 环境变量 → 系统变量 → Path → 编辑”中新增 `D:/Tools/ffmpeg/bin`，重新打开 Git Bash 后检查：

```bash
ffmpeg -version
ffprobe -version
```

## 2. 创建 Conda 环境并安装依赖

```bash
cd /d/Project/vl/VideoLens
conda create -n VideoLens python=3.13 pip -y
conda activate VideoLens
python -m pip install -r requirements.txt
python scripts/download_models.py --verify
```

最后一条命令准备三个必需模型，首次使用必须完成。已建好环境和模型时，只需激活环境；更新依赖时再安装 `requirements.txt`。

## 3. 启动

```bash
cd /d/Project/vl/VideoLens
conda activate VideoLens
bash scripts/start_web.sh --port 8000
```

打开[工作台](http://127.0.0.1:8000/ui)。首次运行在“设置”中完成[云端模型接入](云端模型接入.md)，保存后点击“菜单 → 重启”。日常使用以上命令启动，终端输入 `stop` 关闭。

需要 GPU 时见[本地模型与 CPU/GPU 切换](本地模型与CPU-GPU切换.md)，其他启动参数见[控制台命令](控制台命令.md)。
