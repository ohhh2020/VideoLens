# 前台控制台与网页服务菜单

在已激活 Conda 环境的 Git Bash 中执行：

```bash
bash scripts/start_web.sh --port 8000
```

服务保持在可见终端，输入区有黄色 `<< ` 标识，输入指令后按 Enter。

| 指令 | 作用 |
| --- | --- |
| `help`、`?`、`帮助` | 查看指令 |
| `status`、`状态` | 服务状态、进程号、任务数与三个模型的实际设备 |
| `clear`、`清屏` | 清空终端屏幕与滚动内容，不改写日志 |
| `stop`、`关闭`、`退出`、`exit`、`quit` | 等待任务与请求结束，正常关闭 |
| `restart`、`重启` | 等旧服务结束，再加载代码和配置，创建新日志 |

Ctrl+C 也可正常关闭。未知指令只显示提示，不作为系统命令执行。长任务执行期间关闭或重启会等待推理收尾。

## 网页菜单

右上角菜单提供重启与关闭，复用同一控制台流程。操作时禁用按钮防重复提交，检测到新进程就绪后才提示重启成功。关闭后页面可保留已显示内容，但不能继续处理请求；再次使用须执行启动脚本。

## 启动参数

| 参数 | 含义 |
| --- | --- |
| `--host 127.0.0.1` | 默认本机监听，也支持 `localhost`、`::1` |
| `--port 8000` | 设置端口 |
| `--reload` | 开发时监视前后端变更并正常重启 |
| `--help` | 查看帮助 |

`start.bat`、`python -m backend.web.main` 同样进入前台控制台，参数只与网页启动有关。

本机 IPC 支持程序化发送相同指令。`state/console-端口.json` 包含随机认证信息，不要分享；正常退出后删除。Windows 管道先检查可读字节再读取，避免阻塞读取与原生模型库初始化互锁。

输出规则见[日志文件与格式](日志文件与格式.md)。
