# 日志文件与格式

## 每次启动独立保存

默认位于 `VideoLens-runtime/logs/`，目录由 `logging.directory` 配置：

```text
2026-10-28-1.log
2026-10-28-2.log
2026-10-29-1.log
```

格式为 `YYYY-MM-DD-CNT.log`，同日从 1 开始并按已有最大序号递增，换日重新从 1 开始。启动和 `restart` 都新建文件，独占创建防止并发覆盖。不按大小轮转，不自动删除旧日志。

父控制台统一收集自身与子服务输出，退出信息归入对应启动日志。`clear` 仅清屏；黄色 `<< ` 提示符固定在终端底部输入行，日志在上方区域滚动，不随日志反复打印；提示符、光标定位和清屏控制码都不写入日志。旧版 `zhiying.log` 如存在仍保留。

## 格式与颜色

```text
[2026-10-28 10:00:00][INFO][asyncio_0]: 转写完成，来源 whisper
```

前缀依次为时间、级别、线程名，方括号紧接冒号，再空一个字符。不拼接模块名或冗长任务路径，正文可保留视频号供排查。

终端以白色正文为主，级别与关键状态局部标绿、橙、红。`logging.color` 支持 `auto`、`always`、`never`；根据实际输出句柄识别 ANSI/VT 支持，自动模式尊重 `NO_COLOR`。即使设置 `always`，不支持 ANSI 的输出窗口仍使用纯文本，避免控制码直接显示。子服务是否输出颜色由父控制台传递，日志文件是 UTF-8 纯文本，不含 ANSI 控制码。

## 任务进度和耗时

网页优先使用 SSE 接收进度，连接不可用时才进行串行备用轮询，完成或离开后停止。成功的高频读取不重复打印访问日志，404、500 等错误保留；读取进度不会再次提交视频分析。

阶段记录耗时及跳过/错误状态，结束汇总总时间。并发阶段有重叠，各阶段耗时之和可大于总时间，不表示重复执行。

没有平台字幕时使用必需 Whisper 转写是正常流程。B 站匿名下载提前跳过要求登录的字幕请求，真正的下载、认证和推理错误仍会提示。
