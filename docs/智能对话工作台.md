# 智能视频对话工作台

打开 `/ui`，通过底部输入框发送视频和问题。一个会话对应一个视频，后续可继续追问；历史通过右上角“历史对话”按需展开。首次进入不自动创建或打开会话；新视频请点击“新对话”。

## 输入与发送

- 点击“选择本地视频”打开本机文件选择窗口。选中时只显示名称、大小和完整路径，发送前可以移除；点击发送后才验证视频、建立软链接并分析。拖放视频时如浏览器不能提供完整路径，会要求填写原路径以建立链接。
- 分享文本可以直接粘贴，例如：`帮我分析 https://www.bilibili.com/video/BV…，然后解释作者的主要依据。`
- 只有视频时生成标准分析报告；带有具体问题时，先完成报告，再自动回答该问题。自动问答由服务执行，离开页面不影响已提交任务。
- 问题不必包含“然后”，可以直接放在链接之后或换行填写。例如 `【【CPU推荐】11月价格】https://www.bilibili.com/video/BV… 为什么这些CPU会出现历史最低点？`。Markdown 链接同样支持；标题或链接标签中的问句不作为附加问题。本地视频也可附带“帮我罗列视频中出现的CPU和推荐指数”等要求。
- 首次只有文字时，助手会引导提供视频。多个链接、附件与链接同时出现时，先选择一个来源，避免分析错误的视频。
- Enter 发送，Shift+Enter 换行。“分析选项”中保留语言、标题、强制重跑及跳过指定阶段的开关。

本地视频直接读取原文件，`VideoLens-runtime/data/uploads/local-<附件ID>.<扩展名>` 只存放软链接，不复制整段视频、不计算上传哈希、不分块传输。默认仍限制8 GiB、2小时。分析和播放依赖原位置；移动或删除原文件后需要重新选择。符号链接权限不足时明确报错，不偷偷退回复制。删除视频/对话只清理链接与分析产物，保留原文件。

旧上传和续传内部接口继续兼容已有数据，新网页的本地入口不再使用这些接口。旧上传记录没有原路径时继续显示它现有的文件地址，不凭文件名猜测用户原始位置。

视频库主标题取最近活动的已命名会话，重命名后列表随之更新。同一视频有多个会话时，库中“报告/对话”入口对应当前展示标题的会话。云端视频标题下显示原链接和“文件缓存”入口，本地视频显示真实原路径。

## 报告、引用与播放

用户模式只显示内容概览与关键结论；详细模式显示完整摘要、分析信息、提示与转写入口。设置切换立即作用于当前消息，不重新分析，也不删除完整报告。

回答中的引用可以点击，播放器会展开并跳转到对应时间。浏览器不支持某些视频编码时，报告与文字证据仍可使用。每份报告支持 Markdown 导出。

## 历史与恢复

历史抽屉默认隐藏，点击“历史对话”后按最近活动显示会话，支持分页、重命名和删除。历史对话与视频库双向联动删除：删除视频会清理它的全部关联会话；删除已绑定视频的会话也会删除视频库中的视频、该视频的所有会话、问答、报告、索引与受管缓存。同一视频允许多个独立会话，但任一会话发起删除都会影响该视频全部会话，网页确认框会明确提示范围。未绑定视频的草稿只删除自身与未被其他记录引用的附件。分析或问答运行期间拒绝联动删除。

新会话首次视频分析完成后，复用设置中的云端大模型，根据分析内容自动生成最多 **15 个字符**的中文标题（汉字、字母、数字、空格和标点均计入长度）。前端同步更新历史栏与会话顶部，后续追问不重复命名。从视频库为已有报告新建会话时，也直接依据该报告命名，不重新分析视频。

手动重命名同样限制为 15 个字符；手动标题不会被稍后返回的模型结果覆盖。云端命名失败不影响已经完成的报告与问答，下次提交问题时可再尝试。旧版本没有记录标题来源，因此迁移时保留现有标题，避免覆盖此前的手动命名，不会批量调用云端重命名。

旧版问答按视频和会话分组导入一次；旧报告按当前已保存版本展示。服务重启后，已完成的报告和回答仍可查看；未完成操作显示“已中断”，点击重试才继续。问答阶段失败时只重试问题，不重新执行已完成的视频分析。

同一会话同时处理一个操作；重复点击、刷新和 SSE 重连不会重复提交相同请求。任务失败时不会展示虚假的完成状态。

## 智能层与模型

智能层复用设置中的“云端大模型”，视觉通道仍独立配置。智能层只组织视频任务，不提供通用闲聊，也不会执行模型生成的本地路径或命令。视频链接由程序从用户输入提取，模型只能选择实际候选。

后续可接入视频分类与不同分析策略。当前新分析默认采用 `fast-v3`：固定间隔抽帧、整帧批量识别、全片均匀取样最多32片生成一次报告，不执行局部加密、高清裁图和分层总结。详见[分析与资源配置](完整性分析与资源配置.md)及[回退验收](回退与效率验收.md)。既有报告继续复用，不自动重算。三个必需本地模型及 CPU/GPU 热切换方式保持。

程序先从实际输入确定来源候选，分离分享标题及链接，再保护明确写出的问题和要求。即使智能层漏填 `question`，这些要求仍会进入后端自动问答。多个来源需要先澄清，选择后保留原问题；问题超过2000字符会明确报错，不静默截短。分析失败不执行后续问答；问答失败保留报告，重试只执行问答。详见[自动问答修复与发布验收](自动问答修复与发布验收.md)。
