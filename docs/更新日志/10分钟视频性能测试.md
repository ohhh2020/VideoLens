# 10 分钟视频性能测试

## 条件与方法

日期为 2026-10-28，样本取自公开链接 [BV1kMxM6FECM](https://www.bilibili.com/video/BV1kMxM6FECM) 已下载文件的前 600 秒，容器复制后实际长 **600.033 秒**、约 **29.29 MiB**。仓库不包含样本、用户历史、原报告或密钥。

设备为 Windows 11、Intel Core Ultra 7 255H、NVIDIA RTX 5060 Laptop GPU，Python 3.13。Whisper small、BGE-M3、SigLIP2 实际设备均为 CUDA；当时已配置的文本与视觉模型均为 `qwen3.5-flash`。

采用已启动并预热的服务。首次任务 `force=true`、`resume=false`，不跳过视觉、总结或向量；样本没有平台字幕，转录来源为 Whisper。视觉请求并发上限 8，GPU 向量批量上限 4，Whisper 批量 4。

## 实测结果

| 项目 | 耗时 |
| --- | ---: |
| 服务记录的首次分析总时间 | **73.186 秒** |
| 客户端提交到观察完成 | **73.460 秒** |
| 相同视频缓存复用，客户端观察 | **1.027 秒** |
| 一次非流式完整问答，客户端观察 | **5.366 秒** |

产出 25 段转写、34 个场景、27 个切片、68 张关键帧、95 条向量，以及云端视觉/OCR和 2486 字符总结。未使用模型降级，第二次任务未重新执行模型流水线。

| 阶段 | 记录耗时 |
| --- | ---: |
| 解析 / 探测 | 0.165 / 0.001 秒 |
| 音频提取 | 1.410 秒 |
| Whisper 转写 | 16.616 秒 |
| 场景检测 | 23.300 秒 |
| 时间轴切片 | 0.055 秒 |
| 关键帧与云端视觉阶段 | 25.639 秒 |
| 向量写入阶段 | 6.605 秒 |
| 云端总结 | 21.688 秒 |

并发阶段存在重叠，不能把阶段耗时相加作为总时间。首次总耗时约占视频时长 12.2%，约为 8.2 倍实时速度。客户端数据包含请求和轮询间隔，问答数据是完整回答时间而非首字延迟。

## 复测

用 FFmpeg 截取本地视频前 600 秒并保留音轨，在网页提交片段、勾选强制重跑，保持各步骤启用，记录任务总时间与阶段日志。再取消强制重跑提交同一路径，测量缓存复用；在对话页用固定问题测量完整回答。

首次分析复测应使用新样本路径或清理自己的上次测试记录。计时从服务预热完成后开始。此次测试关闭历史自动归纳，结束后恢复原开关并移除临时基准记录，原有视频数据保留。

## 边界

这是正常桌面环境下单样本、单次观测，不是多轮平均、CPU/GPU 对照或并发压力测试。未计入原视频下载、裁剪准备、权重下载、依赖安装与服务启动。

视频的镜头密度、文字量、云端请求数量、模型版本、限流、网络与显卡占用都会影响速度，不能保证任意 10 分钟视频均在此时间内完成。本测试不等于转写或 OCR 准确率评测。
