# 本地视频软链接与视频库展示验收

验收日期：2026-11-01。

## 使用方式

在工作台点击“选择本地视频”，通过本机文件选择窗口选择原视频。选择后只展示文件名、大小和完整地址，点击发送才验证视频并登记附件、开始分析。取消选择不会创建会话。

本地附件保存在 `VideoLens-runtime/data/uploads/local-u….扩展名`，它是指向原视频的文件符号链接，不是视频副本。分析与播放读取该链接。音频、切片、关键帧、报告等派生产物仍按原有流程存入独立运行目录。

原文件需要保留在原位置；移动或删除后请重新选择。无法创建符号链接时明确报错，不退回复制。当前机器已经验证具有创建符号链接的权限。

浏览器拖放不能可靠提供真实文件路径，因此无法取得路径时会要求填写原文件完整地址，并核对文件名与大小。原生选择窗口适用于网页和服务位于同一台 Windows 电脑的使用方式。

旧版上传记录没有保存原始地址，无法自动还原或迁移，原有缓存继续兼容。

## 视频库规则

- 主标题使用关联对话标题，手动改名后重新加载视频库即可同步。
- 一个视频有多个对话时，优先使用最近活动的已命名对话。尚未命名时临时使用原视频标题。
- 云端视频显示原链接和“文件缓存”入口。
- 本地视频直接显示原文件完整地址，不显示云端文件缓存按钮。
- 视频库进入对话时定位到当前展示标题对应的会话。
- 删除仍遵循视频和对话双向联动规则；清理本地附件仅删除受管链接，不删除外部原视频。
