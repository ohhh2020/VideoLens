# 版本记录

## 2026-11-03 main 更新：AstrBot 接入、转写隔离与关键词试验

### QQ 与 MCP

- 发布可选的 stdio MCP 桥接、AstrBot 知影插件、插件手动同步安装器和无凭据配置模板。
- 回复 Bilibili 原视频触发分析、随附问题自动回答，追问仍引用原视频；按群和用户隔离上下文，复用现有 VideoLens 模型及分析结果。
- 分析和问答默认本地 Markdown 转图片，长图分页、发送真实图片字节；渲染失败明确报错。可选主动视频卡片工具调用 NapCat 生成 Ark 后发送 JSON 消息段。
- 新增[AstrBot 详细接入教程](../功能介绍/AstrBot接入教程.md)，README 提供入口。教程区分首次安装、既有部署、手动同步、真实群聊验收和离线回归。

### 稳定性与性能

- Windows CUDA Whisper 改用常驻独立工作进程，增加无进展超时和异常回收；不因超时或 OOM 切换到 CPU/其他模型，设备热切换关闭旧工作进程。实测条件见[Whisper 修复记录](2026-11-02Whisper原生卡住修复.md)。
- 报告每次只召回一次偏好记忆，复用固定前缀；固定 JSON 消息采用增量预算计算，结束时仍核验完整消息。
- 提供有界 TF-IDF/TextRank 关键词试验，但因未证明不影响云端报告速度，`integrity.keyword_assist` **默认关闭**，日常保留既有评分。试验与回退见[关键词验收](2026-11-03关键词辅助验收.md)。

### 发布范围

本次更新 `main`，保留 `2026-11-1-lts` 的既有快照。源码不包含运行目录、模型、视频、Conda 环境或真实密钥；各轮历史真实验收的条件继续单独保留，不将离线回归写成新一轮 QQ 群实际收图验收。

发布检查见[2026-11-03 发布验收](2026-11-03发布验收.md)。

## 2026-11-01 main 更新：并行分析、记忆空间与界面操作

本次更新发布到 `main`；`2026-11-1-lts` 继续保留原提交 `1e44810`，不随main移动。

### 分析与性能

- 默认新分析升级为fast-v4，移除镜头检测与scenedetect依赖，保留旧快照兼容。
- 字幕、运行检查点及音频内容转写缓存复用；复用解码器，取帧/视觉与转写并行，总结与索引并行。
- 完整句子、表格行、代码块按同一预算选择；OCR去重保留全部时间，关键词与可用BGE分数辅助优先级，不部署额外模型。
- 标准11分26秒1080p视频：同日旧版135.71秒，新版最终完整重跑62.45秒，转写缓存复用轮58.45秒。完整条件及质量边界见[并行分析验收](2026-11-01并行分析验收.md)。
- 恢复控制台各阶段耗时和最终汇总，失败仍打印；复用整份报告只记录本次读取，不冒用历史推理时间。

### 工作台与记忆

- 知影品牌及报告、流式/定稿回答显示头像。
- 记忆库采用单一可折叠空间，不按偏好类型分类展示；支持弹窗新建/修改及多选删除，批量写入失败保留原数据。
- 报告及问答提供“复制 Markdown”，保留原始格式和引用标记；报告复制范围跟随用户/详细视图，提供成功/失败反馈及兼容复制。

### 文档

- `docs/功能介绍/` 记录当前使用方式，`docs/技术分析/` 记录架构、策略和维护，`docs/更新日志/` 保存版本、修复、实测与历史策略。
- README保留项目介绍、流程、快速入口、当前实测摘要和分类导航；旧策略与历史测量不再混在当前说明中。
- 本次发布回归结果记录在[发布验收](2026-11-01发布验收.md)。历史真实测量不因本次文档整理重跑或改写。

## 2026-11-1-lts

此分支保存2026年11月1日首次发布的代码快照（`1e44810`）；main此后继续更新。分支名称用于定位可复现版本，不代表承诺固定维护年限。安装与运行步骤以[README](../README.md)和[快速上手](../快速上手.md)为准。

### 工作台与数据

- Fluent UI对话工作台，支持浅色、深色和跟随系统；历史抽屉默认隐藏，首次进入不创建会话。
- 本地视频通过本机选择窗口登记文件软链接，不复制完整视频；云端视频由实际输入提取链接。
- 视频库主标题与最近活动的已命名对话同步；云端显示原链接和文件缓存，本地显示原地址。
- 视频与对话双向联动删除，忙碌时拒绝删除；外部原文件和仍有引用的共享文件受保护。
- 报告、回答、时间引用、播放、导出及历史恢复在同一工作台完成。

### 分析与模型

- 本地模型仅保留BGE-M3、faster-whisper-small、SigLIP2，严格加载，分别支持CPU/GPU热切换。
- 视觉、OCR、总结和问答使用独立配置的云端通道，不预填私人地址或密钥。
- 新分析默认采用 `fast-v3` 的固定采样、整帧识别与单次代表性报告，保留完整原始证据和动态检索；不自动重算旧报告。
- 保留Conda环境、源码和独立运行目录边界，以及前台控制台、服务菜单、偏好记忆和按启动保存的日志。

### 本次修复

- 修复分享标题后直接提问被吞掉的问题，支持裸链接、Markdown链接和换行问题。
- 补充本地附件的“罗列、整理、归纳”等指令保护。
- 分享标题内的问句不被当作额外用户问题，多来源澄清后继续保留原问题。
- 分析失败停止问答，问答失败只重试问答，幂等请求不重复生成报告和回答。
- 修复问答证据提炼只限token、不限制实际正文导致的扩写和压缩不收敛；增加字符约束、字节校验与收紧重试，不裁切原始证据。

验证结果及真实调用的范围见[自动问答修复与发布验收](自动问答修复与发布验收.md)。源码不包含模型、运行数据、密钥和环境。
