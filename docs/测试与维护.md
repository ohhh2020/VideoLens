# 测试与维护

以下操作使用已激活的 Conda Python 3.13，FFmpeg / FFprobe 按[快速上手](快速上手.md)配置。

## 环境与模型

```bash
python -m pip check
python scripts/preflight.py --json
python scripts/download_models.py --status --verify
```

预检检查依赖、FFmpeg、三个模型及云端配置。云端未填写时报告未就绪，网页仍可启动用于配置；配置通过不等于真实网络调用成功。

## 后端回归

```bash
python tests/run_all.py
```

合成视频和测试数据库放在源码外。模型边界测试通常使用测试替身，不等同于真实权重或云端验收；启动预热验证真实本地模型，真实全流程结果见[性能测试](10分钟视频性能测试.md)。

## 前端回归

运行时不依赖 Node.js 或 npm 构建。开发测试需要 Node.js 和 `jsdom`，应安装在源码外的独立测试目录，例如 `VideoLens-runtime/tests/frontend/`，将对应 `node_modules` 目录设置到 `NODE_PATH`。

执行 `tests/test_web_render.js`、`tests/test_chat_stream.js`、`tests/test_task_progress.js`、`tests/test_memory_web.js`、`tests/test_key_visibility.js`、`tests/test_service_menu.js`，覆盖 Markdown、流式输出、进度、记忆编辑、密钥显隐和菜单。

## 维护与排查

`scripts/reindex_vectors.py` 可重新编码检索索引，`scripts/gc.py` 管理保留策略与孤儿文件。先执行各脚本的 `--help` 并核对目标。模型运行时不要删除权重或替换运行库。

当前日志见 `VideoLens-runtime/logs/`；`state/console-端口.json` 含控制通道认证信息，不要分享。

Git Bash 模型下载若在 0% 报 `FileNotFoundError`，可能是 Conda 默认 CA 路径失效。项目在进程内修复已知默认路径，保持 HTTPS 校验，不覆盖自定义证书。

CPU/GPU、报告模式与记忆开关可在网页修改；云端配置变更需要重启，已有旧报告不会自动重写。
