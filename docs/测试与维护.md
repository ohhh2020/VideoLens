# 测试与维护

以下操作使用已激活的 Conda Python 3.13，FFmpeg / FFprobe 按[快速上手](快速上手.md)配置。

## 环境与模型

```bash
python -m pip check
python scripts/preflight.py --json
python scripts/download_models.py --status --verify
```

预检检查依赖、FFmpeg、三个模型及云端配置。云端未填写时报告未就绪，网页仍可启动用于配置；配置通过不等于真实网络调用成功。

## 后端回归

```bash
python tests/run_all.py
```

合成视频和测试数据库放在源码外。模型边界测试通常使用测试替身，不等同于真实权重或云端验收；启动预热验证真实本地模型，真实全流程结果见[性能测试](10分钟视频性能测试.md)。

## 前端回归

运行时不依赖 Node.js 或 npm 构建。开发测试需要 Node.js 和 `jsdom`，应安装在源码外的独立测试目录，例如 `VideoLens-runtime/tests/frontend/`，将对应 `node_modules` 目录设置到 `NODE_PATH`。

执行 `tests/test_web_render.js`、`tests/test_chat_stream.js`、`tests/test_task_progress.js`、`tests/test_memory_web.js`、`tests/test_key_visibility.js`、`tests/test_service_menu.js`，覆盖 Markdown、流式输出、进度、记忆编辑、密钥显隐和菜单。

完整性版本另外执行 `node tests/test_quality_web.js`，验证质量设置、8 GiB 换算、报告覆盖与增量 SHA256；后端 `test_integrity*.py` 已纳入总入口，覆盖全量摘要、事务发布、15 秒分窗、OCR、动态检索、OOM 缩批及分块续传。8 GiB 测试使用边界元数据，不创建 8 GiB 测试文件。

`scripts/create_integrity_samples.py` 可生成受控的三类 10 分钟样本；`scripts/benchmark_integrity.py --help` 提供隔离真实模型验收入口。运行会使用当前云端配置并消耗额度，所有结果应输出到运行目录的 tests 子目录。验收口径与最新结果见[完整性升级验收记录](完整性升级验收记录.md)。

## 维护与排查

`scripts/reindex_vectors.py` 可重新编码检索索引，`scripts/gc.py` 管理保留策略与孤儿文件。先执行各脚本的 `--help` 并核对目标。模型运行时不要删除权重或替换运行库。

当前日志见 `VideoLens-runtime/logs/`；`state/console-端口.json` 含控制通道认证信息，不要分享。

Git Bash 模型下载若在 0% 报 `FileNotFoundError`，可能是 Conda 默认 CA 路径失效。项目在进程内修复已知默认路径，保持 HTTPS 校验，不覆盖自定义证书。

CPU/GPU、报告模式与记忆开关可在网页修改；云端配置变更需要重启，已有旧报告不会自动重写。

## Fluent 界面回归

使用源码外 jsdom 执行 `tests/test_theme.js` 与 `tests/test_chat_stream.js`，分别验证主题保存/系统跟随，以及空首页不创建会话、纯文字引导、隐藏历史和首次附件/链接发送去重。其余工作台回归仍覆盖 Markdown、报告模式、服务菜单、密钥显示、记忆库与进度流。真实浏览器验证官方 Fluent 组件加载、明暗切换、附件预览、已有报告恢复和 390px 窄屏无横向溢出。详见[界面主题与导航](界面主题与导航.md)。

## 双向删除回归

`python tests/test_conversations.py` 覆盖两个内部删除入口、同视频多会话、忙碌阻止、并发提交、版本与附件清理、共享文件及外部原始素材保护。`node tests/test_linked_delete_web.js` 使用实际前端脚本检查双向列表刷新、取消确认、错误提示与跨标签同步。测试数据放在隔离临时目录，不能使用用户已有视频做破坏性验收。

## 本地软链接与视频库来源

`python tests/test_local_links.py` 验证真实FFmpeg、文件软链接、原文件保护、缓存统计、过期清理、标题与路径响应以及本机选择器协议。`node tests/test_local_link_web.js` 验证选择/取消不建会话、发送才登记链接、无分块上传、云端链接与本地路径展示。原生选择器协议由模拟系统API验证，不自动操作用户的桌面文件选择窗口。

## 自动问答与版本发布

`python tests/test_conversations.py` 包括模型故意漏填问题时的保护回归：嵌套分享标题、裸链接、Markdown链接、链接前后及换行问题、本地附件要求、标题问句不触发问答、多来源澄清后保留问题、2000字符校验、重复发送及问答失败后只重试问答。

`node tests/test_chat_stream.js` 使用当前本机选择与软链接接口，验证空首页不建会话、选择只预览、发送才登记链接、双击去重及问答由后端编排。

`python tests/test_integrity_qa.py` 同时检查证据提炼的预算收敛、所有输入批次及尾部事实保留、扩写/截断收紧重试、错误输出拒收和原始证据不变。

发布只提交源码、无密钥默认配置和文档。排除运行目录、模型、数据库、媒体、日志、密钥配置与Conda环境；先检查暂存区，再将同一个提交推送到 `main` 与版本快照分支。`2026-11-1-lts` 的记录见[版本记录](版本记录.md)，本轮实测见[自动问答修复与发布验收](自动问答修复与发布验收.md)。
