# 版本记录

## 2026-11-1-lts

此分支保存2026年11月1日的代码快照，`main` 同步包含本次发布内容。分支名称用于定位可复现版本，不代表承诺固定维护年限。安装与运行步骤以[README](README.md)和[快速上手](快速上手.md)为准。

### 工作台与数据

- Fluent UI对话工作台，支持浅色、深色和跟随系统；历史抽屉默认隐藏，首次进入不创建会话。
- 本地视频通过本机选择窗口登记文件软链接，不复制完整视频；云端视频由实际输入提取链接。
- 视频库主标题与最近活动的已命名对话同步；云端显示原链接和文件缓存，本地显示原地址。
- 视频与对话双向联动删除，忙碌时拒绝删除；外部原文件和仍有引用的共享文件受保护。
- 报告、回答、时间引用、播放、导出及历史恢复在同一工作台完成。

### 分析与模型

- 本地模型仅保留BGE-M3、faster-whisper-small、SigLIP2，严格加载，分别支持CPU/GPU热切换。
- 视觉、OCR、总结和问答使用独立配置的云端通道，不预填私人地址或密钥。
- 新分析默认采用 `fast-v3` 的固定采样、整帧识别与单次代表性报告，保留完整原始证据和动态检索；不自动重算旧报告。
- 保留Conda环境、源码和独立运行目录边界，以及前台控制台、服务菜单、偏好记忆和按启动保存的日志。

### 本次修复

- 修复分享标题后直接提问被吞掉的问题，支持裸链接、Markdown链接和换行问题。
- 补充本地附件的“罗列、整理、归纳”等指令保护。
- 分享标题内的问句不被当作额外用户问题，多来源澄清后继续保留原问题。
- 分析失败停止问答，问答失败只重试问答，幂等请求不重复生成报告和回答。
- 修复问答证据提炼只限token、不限制实际正文导致的扩写和压缩不收敛；增加字符约束、字节校验与收紧重试，不裁切原始证据。

验证结果及真实调用的范围见[自动问答修复与发布验收](自动问答修复与发布验收.md)。源码不包含模型、运行数据、密钥和环境。
