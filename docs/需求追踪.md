# 需求追踪与验收对应

依据：已批准的 [Plan.md](Plan.md) 与原始需求文档。下面把需求对应到实际模块和验证方式。“实现”表示代码入口存在并纳入测试范围；真实服务、质量与性能是否达标，必须看 [测试报告](测试报告.md) 的实测结果。

## 1. 核心能力

| 编号 | 需求 | 主要实现 | 验证及验收边界 |
|---|---|---|---|
| F01 | 本地视频/URL、大小时长限制、流式处理 | `api.py`、`service.py`、`media.py` | 上传边界、真实 FFprobe；平台在线下载需可达样本 |
| F02 | 字幕优先、SRT/VTT/ASS、语言选择 | `media.read_subtitles/find_subtitles` | 不同字幕格式、中文文本、异常与空字幕 |
| F03 | 16kHz 单声道、真实 ASR、CPU 降级 | `media.extract_audio`、`ModelGateway.transcribe` | 真实 FFmpeg、中英文人声；GPU 单独记录 |
| F04 | 目标 20 秒、范围 5—60 秒可调切片 | `media.make_clips`、`config.Settings` | 句界、短视频、无语音、时间边界 |
| F05 | 场景帧、补采样、去重、尺寸与字节记录 | `media.extract_frames` | 真实场景视频、静态重复帧、低分辨率 |
| F06 | 视觉描述及 OCR，关联原帧 | `ModelGateway.describe` | 协议测试；真实云端视觉待有效配置 |
| F07 | BGE-M3、SigLIP2 本地检索 | `models.py`、`retrieval.IndexManager` | 实际权重、编码及 Chroma 查询，不能用 Mock 代替 |
| F08 | 加权 RRF、缺失通道重归一、关键词降级 | `retrieval.fuse_rankings/search` | 排序、去重、通道失败与空结果 |
| F09 | 章节、时间线、关键词、标签与摘要 | `generation.Composer.report` | 结构与证据校验；实际生成另测 |
| F10 | 多轮会话、视频隔离、上下文预算 | `service.py`、`generation.py` | 跨视频会话拒绝、长历史与预算边界 |
| F11 | 引用 ID、摘录校验、一次修正 | `generation.validate_claims/compose` | 不存在 ID、伪造摘录、修正失败降级 |
| F12 | 云端→本地→基础摘录 | `ModelGateway`、`Composer` | 模拟超时/断流与真实本地服务；云端待配置 |
| F13 | 暂停、恢复、取消、崩溃重启 | `service.VideoService`、`store.Database` | 任务状态、检查点、幂等与重启恢复 |
| F14 | SQLite 主存储与可重建 Chroma | `store.py`、`retrieval.py` | 索引失败、版本切换、重建与一致性 |
| F15 | TTL、级联删除与容量约束 | `service.cleanup/delete_video` | 活跃任务保护、原文件保护、过期清理 |

## 3. 明确保留的验收边界

- 未配置有效云端服务时，真实文本/视觉/OCR验收标记为待配置；网络替身测试只能证明协议处理。
- 静态构建与依赖安装成功不等于 GPU 推理成功。PyTorch、CTranslate2、llama.cpp 分别记录 CPU/CUDA。
- 两个短语音样本只用于功能和初步误差测量，不能用其结果代表大规模中文/英文准确率。
- 720p 与 200KB 目标受源视频和可读性限制，报告实际值与偏差。
- 一小时 720p 低帧率合成字幕专项已通过；真实长音频、稳定延迟、人工问答集和 8GB 内存仍有明确边界，见测试报告。
- Linux 后端适配、公网部署、Obsidian、MCP、QQ-Bot 和浏览器扩展保留为后续工作，不包含在本次首版已实现清单。
